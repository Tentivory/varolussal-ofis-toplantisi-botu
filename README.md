# Varoluşsal Ofis Toplantısı Botu

Bu repository, insanlığın en büyük krizlerinden biri olan **ofis toplantıları**nın varoluşsal boyutunu ele alan devrim niteliğinde bir yazılımdır.

## Ne Yapar?

- Sonsuz sürede bitmeyen toplantı gündemleri üretir.
- Katılımcıların "acaba ne zaman bitecek" düşüncesini maksimize eder.
- Her 3 dakikada bir "sadece kısa bir güncelleme" diye başlar.
- Asla gerçek bir karar çıkarmaz. Çünkü karar çıkarsa toplantı biter ve bu kabul edilemez.

## Kurulum

```bash
pip install nothing  # Hiçbir şey kurmaya gerek yok, toplantı zaten kurulu
python toplantisi.py
```

## Uyarı

Bu botu çalıştırmak, gerçek bir toplantıya katılmaktan daha az yorucudur ama daha az anlamlıdır. Şirketinizde kullanmayın, yoksa yükseltme alırsınız.
